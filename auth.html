Bulut Kurulumu

Hesaplı sisteme geçmeden önce bir kere Firebase projeni bağlaman gerekiyor.

1) console.firebase.google.com'a git, ücretsiz yeni proje oluştur.
2) Sol menüden Authentication → "Get started" → Email/Password sağlayıcısını aç.
3) Sol menüden Firestore Database → "Create database" (test modunda başlat).
4) Proje ayarlarından (⚙️ → Project settings → Genel) "Web uygulaması ekle" (</> simgesi) ile bir web app oluştur, sana verdiği firebaseConfig nesnesini aşağı yapıştır:
